# Hong Kong Border Traffic Forecasting

A reproducible time-series forecasting project using the Hong Kong Immigration Department's official daily passenger traffic data.

The project forecasts **daily Mainland visitor arrivals to Hong Kong**, aggregated across control points. It compares a seasonal-naive baseline, Ridge Regression, and Histogram Gradient Boosting using an expanding-window walk-forward backtest.

## 1. Real data and provenance

**Primary source:** Hong Kong Immigration Department, *Statistics on Daily Passenger Traffic*.

- Official CSV: https://www.immd.gov.hk/opendata/eng/transport/immigration_clearance/statistics_on_daily_passenger_traffic.csv
- Dataset page: https://data.gov.hk/en-data/dataset/hk-immd-set5-statistics-daily-passenger-traffic
- Data specification: https://www.immd.gov.hk/opendata/eng/transport/immigration_clearance/data_specification_for_statistics_on_daily_passenger_traffic.pdf
- Local snapshot included in this repository: `data/raw/statistics_on_daily_passenger_traffic.csv`
- Snapshot date range: **1 January 2021 to 25 November 2026**
- Snapshot size: **63,762 rows** (as downloaded for this analysis)

The raw file contains daily records by control point and direction, with separate counts for Hong Kong residents, Mainland visitors, and other visitors. The date format in the source is DD-MM-YYYY.

The included raw CSV is the actual official-source file used to produce the results below. This makes the reported analysis reproducible without relying on a live download. The official source may change as new daily observations are published; a refreshed download can therefore produce different results.

## 2. Reproduce the analysis

Requires Python 3.10+.

```bash
pip install -r requirements.txt
python main.py --csv data/raw/statistics_on_daily_passenger_traffic.csv
python run_tests.py
```

To fetch the latest version directly from the official source:

```bash
python main.py
```

For software tests only (not empirical results):

```bash
python main.py --offline
```

`--offline` generates synthetic data for testing. **Do not use offline-mode output as real-world findings or CV metrics.**

## 3. Target construction and cleaning

- Direction: **Arrival** only.
- Visitor group: **Mainland visitors** only.
- Aggregation: daily sum across individual control points.
- Analysis start: **6 February 2023**, selected as the post-reopening start date to avoid training across the COVID-era structural break.
- The downloaded snapshot has no pre-aggregated `Total` control-point rows, so the loader sums the individual control points. If a future version contains a `Total` row, the loader uses that aggregate row instead of summing both aggregate and component rows.
- The daily series contains **1,389 consecutive dates** from 6 February 2023 through 25 November 2026, with no missing values after the limited short-gap interpolation step.

Processed target series: `data/processed/daily_mainland_visitor_arrivals.csv`.

## 4. Forecasting methodology

- Forecast horizon: **7 days ahead**.
- Validation: **12 expanding-window walk-forward folds**, each with 30 test days (360 out-of-sample predictions in total).
- Models:
  - Seasonal naive: same weekday from the prior week (7-day lag).
  - Ridge Regression with standardisation and cross-validated regularisation.
  - Histogram Gradient Boosting Regressor.
- Features: calendar variables, selected public-holiday/event flags, lagged values, and shifted rolling statistics. Features for each target date are constructed using observations available at least 7 days before that date.
- Metrics: Mean Absolute Error (MAE), Mean Absolute Percentage Error (MAPE), and Root Mean Squared Error (RMSE).

The validation is a historical backtest, not a guarantee of future performance. Holiday flags are hand-built approximations rather than a complete official calendar.

## 5. Results on the included real-data snapshot

These metrics were generated by running `main.py` against the bundled official-source CSV (not synthetic data).

| Model | MAE (passengers) | MAPE | RMSE (passengers) |
|---|---:|---:|---:|
| Seasonal naive | 24,996.09 | 21.64% | 40,675.39 |
| Ridge Regression | 21,370.61 | 17.57% | 29,479.82 |
| Histogram Gradient Boosting | 18,801.93 | 14.93% | 29,335.15 |

On this backtest, Histogram Gradient Boosting achieved **31% lower MAPE** than the seasonal-naive baseline. This is a result for this specific snapshot, target definition, feature set, and validation window; it should not be interpreted as a guarantee of future accuracy.

The model's MAPE on dates flagged as holiday weeks was **34.3%**, compared with **13.8%** on other dates. This suggests performance is weaker around the holiday periods represented by the current hand-built flags.

## 7. Tests

Run `python run_tests.py`. The test suite checks date continuity, arrival-only aggregation, feature leakage safeguards, model/backtest ordering, column normalisation, and protection against double-counting an aggregate `Total` row.

## 8. Limitations

- The analysis begins in February 2023 and does not model the COVID closure period.
- Holiday flags are hand-built and may miss special events or date changes.
- No weather, exchange-rate, event, transport-capacity, or policy variables are included.
- The aggregate target can hide differences between individual border control points.
- Official statistics may be revised; refreshed source data can change the results.
- A 7-day-ahead historical backtest does not establish performance under future structural changes.
